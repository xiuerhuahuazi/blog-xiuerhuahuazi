## 三、双采极清生图流：逐段拆解

整条流被 `Fast Groups Bypasser (rgthree)` 劈成四段，想跑哪段开哪段：

| 分组 | 干什么 | 关键参数 |
|---|---|---|
| ① Krea2-一采出图 | 定构图、定内容 | 8 步，cfg 1，euler + simple，denoise 1.0，1MP |
| ① Krea2-二采出图 | latent 先放大 1.5×，再重采样补细节 | **5 步，cfg 1，denoise 0.5** |
| ② Krea2-高清重绘2 | 定稿后再做一次重绘 | 低步数 + 低 denoise，只做收边 |
| SeedVR2-7/3b-int8 图像放大 | 最终超分 | SeedVR2 7b int8 + `OmniSR_X4_DIV2K` |

**模型配置（这一段最值得抄）**

- 底模：`Krea2-Moody-Mix-premium_int8_convrot`（社区特调版，不是原版 turbo）
- 文本编码器：`qwen3vl_4b_bf16`，CLIP type 必须选 `krea2`
- VAE：`qwen_image_vae`
- LoRA ①：`Krea2-亚洲hina_krea2Turbo_lora_tqd_v4.0`，权重 1
- LoRA ②：`krea2_turbo_lora_rank_64_bf16`，权重 1
- 分辨率：ResolutionSelector，9:16，1MP，multiple 8
- 收尾锐化：`ImageSmartSharpen+`（7, 0.75, 5, 0.5）

**UltimateSDUpscale（另一条放大路径，与 SeedVR2 二选一）**
2× 放大，分块 1024×1024，4 步，euler/simple，**denoise 0.2**——denoise 就是这个节点的"重绘强度"，0.2 保结构，往上就改内容了。

**双采的逻辑一句话**：一采在 1MP 上把构图和内容定死；二采把 latent 放大 1.5 倍后只重绘 50%（denoise 0.5），所以细节变多但构图不变；最后 SeedVR2 用扩散放大把纹理"重画"出来，而不是插值拉伸。这跟抖音上那套"二次采样 0.2→0.35"是同一个原理，只是这里用 denoise 0.5 换更强的细节增益。

**节点依赖**：`rgthree-comfy`（分组开关/种子/对比）、`ComfyUI_UltimateSDUpscale`、SeedVR2 系列节点、`ImageSmartSharpen+` 等第三方节点。打开时报红就按缺失节点提示装，作者在 Note 里也给了节点包网盘。

## 四、这条流里最值钱的东西：一条中文"论文式"长提示词

它的 `CLIPTextEncode` 里不是短句，而是一整篇分段结构的中文提示词。结构如下（可直接当模板抄）：

```
标题：<角色名>（<主色调> · <场景>）
主体： <谁、发色瞳色、服装材质与配饰、姿态、整体氛围>
要点： <3 个视觉符号，说明它们共同传达什么主题>
前景： <占画面哪块、什么物件、和主体怎么衔接>
中景： <主体半身/全身动作、材质在光下的表现>
背景： <环境、光源位置、剪影层次、空气介质>
构图： <画幅比例 + 重心 + 机位角度 + 前景占比>
视觉引导： <视线怎么被牵到主体>
色调： <主色 + 辅色 + 对比方式>
风格： <什么美学体系 + 细节精致度描述>
光影氛围： <主光方向 + 轮廓光 + 环境粒子 + 情绪>
```

原文示例（节选，全文在 JSON 里）：

> **主体**：画面核心是一位赤发炽烈的女性舞姬，她身披由鎏金流苏与绯红轻纱构成的华美舞衣，肌肤如蜜色琥珀般泛着暖光，瞳孔如熔金落日般燃烧着灼灼光焰……
> **中景**：画面中央区域是角色的半身特写，她舒展双臂如展翼，右手高举间指间金铃轻颤……
> **背景**：背景是一片燃烧般的黄昏沙漠神殿，巨大的落日悬于地平线，将整片天空染成绯红与鎏金的渐变……
> **构图**：采用竖版 9:16 偏右重心 + 低角度仰视构图……
> **光影氛围**：采用逆光剪影与暖调轮廓光的双重打光，主光源来自画面右上方低垂的落日……

**注意它和英文官方示例的区别**：中文这套是"美术指导式"的（讲氛围、讲视觉引导、讲主题），英文官方那套是"物理事实式"的（讲镜头、讲光向、讲材质）。两种都成立，但中文这套更容易写出 500 字以上还不跑题，因为每一段都有小标题约束自己。

**风险**：这种写法里"史诗级""灼热生命力"这类词对模型没有信息量，只是占字数。真要压缩，就把"要点/视觉引导/风格"三段砍掉，保留主体、前景、中景、背景、构图、色调、光影七段。

## 五、四视图流（角色设定集）

16 个节点，走的不是文生图，而是 **Krea2 的 Edit 分支**：

- `Krea2EditGroundedEncode` ×2 + `Krea2EditModelPatch`：这是 Krea2 的图生图/编辑编码节点，靠参考图 + 文本锚定
- LoRA：`Krea2-四视图QuadView_krea2_v1` + `krea2-Cc风情万种-风格`
- KSampler：10 步，cfg 1，euler/simple，denoise 1
- 底模：`krea2_turbo_fp8_scaled`（原版，不是特调）
- 输入一张参考图，输出同一角色的多视角设定图

做法：先出一张满意的角色立绘 → 丢进这个流 → 用 QuadView LoRA 拉出正/侧/背视图 → 三张拼成设定集。适合做角色卡、短剧人物设定。

## 七、复刻这份双采流的最短路径

1. 装 ComfyUI + `rgthree-comfy` + `ComfyUI_UltimateSDUpscale` + SeedVR2 节点包
2. 下四个文件：`Krea2-Moody-Mix-premium_int8`、`qwen3vl_4b_bf16`、`qwen_image_vae`、两个 LoRA
3. 拖入 JSON，先只开 ① 一采出图，跑通 8 步 / cfg 1
4. 满意后开 ① 二采，denoise 从 0.5 起，嫌改太多就降到 0.35
5. 最后开 SeedVR2 段，放大倍数别一次拉满
6. 每一步都存 seed，方便回溯
