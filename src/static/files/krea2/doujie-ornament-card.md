# 豆姐 · 角色饰品卡（跨图一致性用）

任何一张图里出现豆姐，都照这份清单写，缺一件就会和别的图对不上。

## 固定五件（按位置从前到后）

1. **暖橙色豆形发饰**：圆润的豆子形状，约拇指盖大小，别在右耳前侧，是画面里少数亮点。
2. **深红大丽花**：插在同一侧的耳上方偏后，花瓣细密、被逆光穿透后边缘发亮。
3. **黑色蕾丝小头纱**：极小的 fascinator，斜插在大丽花之后、位置最高，半透、花边细碎。
4. **两串金色小流苏**：从头纱下缘垂落，每串末端收拢，随头动会轻轻晃。
5. **一枚铜质小吊坠**：接在流苏下端，圆形、带一点磨旧的哑光。

## 位置关系（必须写清，否则会互相遮挡）

头纱最高、靠后 → 大丽花在中间偏后 → 豆形发饰最低、最靠前，三者沿右耳上缘排成一条斜线。

## 服装（成对出现）

米白色高领针织毛衣 + 暖橙色短马甲，袖口有细密金色绣线。

## 手持物

一叠微微发光的纸页，纸边溢出金色细光，会向上飘几粒光点。

## 禁止项

不穿深色斗篷、背后没有金色十字、不戴兜帽。

## 跨图复用时的一句话模板

「豆姐：深栗色齐肩短发内扣，右耳上缘自后向前依次为黑色蕾丝小头纱（垂两串金色小流苏与铜质吊坠）、深红大丽花、暖橙色豆形发饰；米白高领针织毛衣配暖橙短马甲；怀里抱一叠发光的纸页。」
