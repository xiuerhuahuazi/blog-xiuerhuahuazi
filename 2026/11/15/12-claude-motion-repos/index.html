12 个让 Claude 做动效的仓库：清单、实测 star 与选型

一条 X 帖列了 12 个「Claude + 动效」仓库。我逐个核了 star、仓库状态与真实用途，并给出按任务选的三条路径。

目录

  1. 清单
  2. 怎么选：按任务，不按 star

Y0urDumble 在 X 上发了一条清单：fable 5.2 + 12 个仓库，把「一个想法」变成「一支片子」。原帖我放在文末。

这类清单最容易虚标 star。我把 12 个仓库逐个用 GitHub API 核了一遍（2026-11-15），全部存在、都没有归档，star 数与原帖基本对得上（原帖是四舍五入到 K）。下面按原帖顺序列出，括号里是实测值。

清单

  1. hyperframes（https://github.com/heygen-com/hyperframes）——写 HTML，直接出视频；实测 84,504 ★（原帖 83K）。HeyGen 出品，适合把网页动效渲染成片子。
  2. remotion-skills（https://github.com/remotion-dev/skills）——Remotion 官方给的 React 视频技能；7,189 ★（6.8K）。做「用代码写视频」的正路。
  3. blender-mcp（https://github.com/ahujasid/mcp-for-blender）——让 Claude 直接驱动 Blender；34,480 ★（34K）。3D 场景与渲染的入口。
  4. gsap-skills（https://github.com/greensock/gsap-skills）——GSAP 官方的缓动与时间线技能；18,474 ★（18K）。网页动效的底座。
  5. anatomy（https://github.com/wheresryan22/anatomy）——把任何想法变成可用的 3D 物体；27,395 ★（27K）。偏资产生成。
  6. pixelfx（https://github.com/patch-gg/pixelfx）——244 个代码实现的像素特效；7,523 ★（7.1K）。做复古/故障感时翻。
  7. video-shotcraft（https://github.com/Vincentwei1021/video-shotcraft）——电影感产品宣传片；19,793 ★（19K）。偏分镜与镜头语言。
  8. openmotion（https://github.com/nexu-io/openmotion）——全栈动态视频工作台；9,976 ★（9.6K）。想把「生成—编辑—导出」放一条流水线时看。
  9. opencreator（https://github.com/krillinai/OpenCreator）——把视频配音成 120+ 种语言；14,367 ★（14K）。后期本地化。
  10. impeccable（https://github.com/pbakaus/impeccable）——清掉 UI 里的「AI 味」；110,438 ★（108K）。不是动效工具，但做画面质感时最实用。
  11. garden-skills（https://github.com/ConardLi/garden-skills）——动效 showreel 与视频 deck；15,195 ★（15K）。做作品集与提案时用。
  12. anthropic-skills（https://github.com/anthropics/skills）——官方前端与 canvas 设计技能；194,934 ★（193K）。底座型仓库，先装它再谈别的。

怎么选：按任务，不按 star

路径 A：我要「一个网页变成一支视频」。 先 hyperframes，再 remotion-skills。前者最快出片，后者可控性更强；两个都吃 HTML/React 的底子。

路径 B：我要「3D 场景/产品动画」。 blender-mcp + anatomy。前者负责让 Claude 操作 Blender，后者负责把想法变成可用的 3D 物体；pixelfx 只在需要像素风时加。

路径 C：我要「画面更高级，但不想学新工具」。 impeccable + anthropic-skills + gsap-skills。先把 UI 的「AI 味」清掉，再谈动效；gsap 负责网页里的节奏。

三个提醒：

  • star 不等于质量。 这份清单里 star 最高的两个（anthropic-skills、impeccable）都不是「动效工具」，而是底座与审美修正；真正出片的仓库 star 反而低。
  • 「skill」不是「app」。 remotion-skills、gsap-skills、garden-skills 这类是给 Claude 的技能包/示例集，装完要自己接流程，不是双击出片。
  • 模型名与版本会漂。 原帖写的是 fable 5.2；仓库本身与模型无关，换成别的模型也能用，别被版本号吓住。
